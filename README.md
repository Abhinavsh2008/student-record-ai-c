AI-Assisted Student Record and Result Management System

Project Description

This project is a console-based Student Record and Result Management System developed using C programming language.

It helps manage student records, calculate CGPA, and provide simple academic advice based on student performance.

Features

1. Add Student Details
2. Search Student by SAP ID
3. Display All Students
4. Calculate CGPA
5. Calculate Average CGPA by Year
6. Delete Student Record
7. Sort Students by SAP ID
8. Sort Students by Name
9. AI Academic Advisor
10. Exit

Technologies Used

- C Programming Language
- GitHub
- GitHub Codespaces
- ChatGPT for learning assistance

How to Run

Compile:

"gcc 590034549.c -o student"

Run:

"./student"

CGPA Calculation

CGPA = Sum of available SGPA values / Number of available SGPA values

Academic Advisor

- CGPA 9–10: Excellent Performance
- CGPA 8–8.99: Good Performance
- CGPA 6–7.99: Needs Improvement
- CGPA below 6: Requires Immediate Attention

The academic advisor uses simple if-else statements in C. No external AI API is used.

AI Usage

ChatGPT was used for understanding C programming concepts, debugging, preparing test cases, and improving documentation.
